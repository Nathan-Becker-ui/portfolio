CASE 07 · DESIGN SYSTEM

Design System

The system behind this portfolio: tokens, type and components that power the site, the PDF and the resume, in two languages and two screen widths.

ROLE

Design system, UI and art direction

PROJECT

Personal portfolio (real, live)

YEAR

2026

TOOLS

Figma, Claude, Tailwind, Vercel

01 — CONTEXT

SITE · PDF · RESUME · PT AND EN

Three deliverables, two languages, one visual language.

The project

A portfolio with a website, a PDF and a resume, in Portuguese and English, for desktop and mobile. Without a system, every new piece would be designed from scratch and the three deliverables would drift apart.

The system in numbers

Everything comes from the same variables and styles in Figma: changing one value changes all three deliverables at once.

VARIABLES

68, in 3 collections

STYLES

31 text and 8 effect styles

SCREENS

28 site screens, in 2 languages
